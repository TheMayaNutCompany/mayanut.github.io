# 🤝 Contributing Guide  
## The MayaNut Company Website Project

Thank you for your interest in contributing to this project.

Whether you are improving translations, refining the UI, correcting documentation, contributing research-based content, or submitting original media, your work helps support a broader effort to increase awareness of **MayaNut™ Flour**, the Alicastrum tree, and *Brosimum alicastrum*.

Before contributing, please:

- Read the **Code of Conduct**
- Follow the guidelines below
- Test your changes before submitting

---

## 1️⃣ Ways to Contribute

You may contribute by:

- Fixing typos or improving documentation
- Enhancing translations
- Refining layout or UI behavior
- Adding accurate, research-based content
- Improving accessibility
- Improving SEO or metadata quality
- Reporting or fixing bugs
- Submitting original images or graphics relevant to the project

If you plan to make code or content changes, fork the repository first and work from your own branch.

---
